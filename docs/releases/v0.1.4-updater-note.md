# In-app update fix (branch fix/updater-014): note for the next release's notes

**Symptom on Windows (0.1.3, reported 2026-11-10):** Update downloaded, **Restart to update** closed
Lens, but the new version was never installed and Lens did not reopen.

**What changed (ships in the next version):** *Restart to update* now quits for real (no hide to the
tray), stops every helper process Lens started (ffmpeg / whisper-cli run from inside the install folder
and kept it locked; the installer only closes `Lens.exe`), then runs the installer silently and
relaunches. If the installer cannot be started, Lens stays open and shows **Download installer
manually**, which opens the release page. Every step is written to `lens.log`.

## Important: one manual install is needed

The update is carried out by the version you are **running**, so the fix only helps updates **from**
the fixed version onwards. **Users on 0.1.3 (or older) must install the next version manually once:**
download `Lens-Setup-<version>.exe` from the GitHub release page and run it (close Lens from the tray
first: tray icon → Quit Lens). Settings (`%APPDATA%\Lens`) and recordings (`Videos\Lens`) are kept.
After that, in-app updates install on their own.

Suggested line for the release notes:

> **Upgrading from 0.1.3:** the in-app update in 0.1.3 could close Lens without installing. Download
> `Lens-Setup-<version>.exe` from this page and run it once (Quit Lens from the tray first); your
> settings and recordings are kept. From this version on, **Update → Restart to update** works again.

## Verification level

- Unit tests (`apps/desktop/test/updater.test.ts`, `children.test.ts`) and a real-Electron Linux test
  with a stand-in installer (`apps/desktop/e2e/update-install.spec.ts`).
- **Not verified on Windows:** the NSIS installer run by the update was not exercised (no Windows
  machine in the build sandbox). Check on Windows before publishing: install the fixed version, publish
  a newer test release, click Update → Restart to update, and confirm Lens reopens on the new version;
  `lens.log` should show `[update] quitAndInstall(...)` and `electron-updater: Executing: ...`.
- If it still fails on Windows, run the downloaded installer by hand from
  `%LOCALAPPDATA%\lens-updater\pending\` without `/S`: NSIS then shows the reason it stops
  ("cannot be closed" / "failed to uninstall old application files").
