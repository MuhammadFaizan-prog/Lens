Lens 0.1.4 fixes the in-app update on Windows, makes the editor panes resizable, adds aspect framing modes, a dedicated 3D inspector, many more backdrops and a second round of caption fonts, and opens heavy projects faster.

**Upgrading from 0.1.3 (one manual install needed):** the in-app update in 0.1.3 could close Lens without installing the new version. Download `Lens-Setup-0.1.4.exe` from this page and run it once (quit Lens from the tray first: tray icon → **Quit Lens**). Your settings (`%APPDATA%\Lens`) and recordings (`Videos\Lens`) are kept. From 0.1.4 on, **Update → Restart to update** works again.

**Windows SmartScreen:** the installer is not code-signed yet, so Windows may show "Windows protected your PC". Click **More info → Run anyway**.

## Fixes

- **In-app update installs again**: *Restart to update* now quits for real (no hide to the tray), stops every helper process Lens started (ffmpeg / whisper-cli kept the install folder locked), then runs the installer silently and relaunches Lens. If the installer cannot start, Lens stays open and offers **Download installer manually**. Every step is written to `lens.log`.
- **Resizable panes**: the timeline's lane-header column and the inspector can be resized by dragging, so labels like "Audio" are no longer cut off.
- **Fullscreen preview**: toggling **F** off right after turning it on now leaves fullscreen reliably.
- **Inspector sliders**: wider sliders with labels that fit ("Zoomed size") at 1366×768, and a thin inspector scrollbar.

## New

- **Aspect framing**: when you change the aspect ratio, choose how the recording fills it: **Fit**, **Fill**, **Follow cursor** or **Custom** crop, with the screen card centred.
- **3D inspector**: a dedicated 3D tab with a template tile grid, reset per value, typed numeric input, larger sliders and working keyframes.
- **63 backdrops**: many more background images (our own generated art) in the Background picker.
- **Caption fonts 2**: 44 caption fonts and 20 caption styles, plus **font import** (from a file, a URL or Google Fonts).

## Performance

- **Heavy projects open faster**: first paint of a heavy project went from 5,264 ms to 4,089 ms (about 22 % faster), measured on the same 2-core arm64 Linux sandbox as 0.1.3's numbers.

## Known limitations

- Tested on the packaged **Linux** build only; **not yet tested on Windows** (including the update installer itself).
- Users on 0.1.3 or older must install 0.1.4 manually once (above).
- The installer is unsigned (SmartScreen, above).
- Logs are at `%APPDATA%\Lens\logs\lens.log`; use **Open log folder** to find them and attach the log when reporting a bug.
